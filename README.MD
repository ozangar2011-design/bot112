Чтобы получить токен от телеграм-бота, надо в самом телеграм-поисковике написать официальному боту от телеграма @BotFather.
Затем /newbot, ставишь своему будущему боту имя и юзернейм, бот отправит вам сообщение с юзернеймом и токеном (по-типу 0:AAGkZSqxiXAPGKm-l4sHUhlVs_NJeMu2I8I).
Этот токен копируем и вставляем токен, я в коде подметил куда. Затем надо открыт терминал и ставит (pip install pyTelegramBotAPI),если его не написат в 
терминал будет выдавать ошибки.
